한 문장으로 이해하기

VOCA HERO!는 영단어 퀴즈의 정답과 반복 학습을 캐릭터 성장·수집·길드 협동에 연결하고, 교사가 학생별 학습 내용을 배정하고 성취를 분석할 수 있는 웹 기반 영어 학습 게임입니다.

퀴즈뜻·발음·철자
기록정답·오답·숙련
성장장비·펫·스킬
협동길드·월드보스
운영 원칙: 게임 기능은 학습을 지속시키는 보상 구조입니다. 수업에서는 모든 기능을 한꺼번에 설명하기보다 퀴즈 전투 → 보상 → 성장 → 길드 순으로 소개합니다.

2공통: 계정과 개인정보

새 학생 계정

  • 실명 대신 한글·숫자 2~12자의 닉네임
  • 학습할 영단어 학년 선택
  • 학습 기록 저장 안내 필수 확인
  • 전체 랭킹 공개는 선택

새 계정에는 학교명·실명·반·번호·주소·전화번호를 저장하지 않습니다.

Google 계정 연동

  • 현재 용사 기록을 Google 계정에 연결
  • 다른 기기에서 같은 기록 이어하기
  • 연동 후 첫 화면의 Google 이어하기 사용
  • 필요하면 설정에서 연결 해제

연동은 새 용사를 추가로 만드는 기능이 아닙니다.

서비스에서 처리하는 정보

학생교사
인증 UID, 닉네임, 학습 학년, 게임 진행·학습 기록과 설정Google 인증, 교사 이름, 학교명, 재직 확인 자료와 길드 관리 기록
교사에게 길드 닉네임과 학습·게임 성취가 표시됩니다.이름·학교는 재직 확인과 같은 학교 길드 연결에 사용됩니다.
닉네임 주의: 이름·학교·학년반번호 같은 개인정보나 부적절한 표현을 넣지 않습니다.

기존 기록 가져오기

업데이트 이전 기록이 있는 경우 가입 화면의 기존 게임 기록 가져오기를 이용합니다. 예전 학교·반·번호·이름은 기존 기록을 한 번 찾는 용도로만 사용하며 새 계정에는 저장하지 않습니다.

3교사: 가입·길드·초대

교사 로그인첫 화면 왼쪽 위
재직 확인학교·이름·증명서
길드 생성기본 단어 수준
학생 초대코드·QR·링크

가입

  1. Google로 교사 로그인
  2. 학교정보 검색 결과 선택
  3. 교사 이름 입력
  4. 최근 1개월 이내 재직증명서 제출
  5. 검토 후 학교 길드 본부 이용

길드와 권한

  • 처음 만든 교사: 길드 마스터
  • 같은 학교 인증 교사: 공동 관리자 참여 가능
  • 마스터 위임·공동 관리자 내보내기
  • 학생용과 관리자용 초대 코드는 별도

실제 초대·권한 관리 화면. 식별 정보는 자료용 예시 이름으로 익명화했습니다.

초대 코드는 영문 대문자와 숫자가 섞인 6자리입니다. 노출되면 새 코드로 갱신합니다.
재직증명서는 주민등록번호·주소·전화번호 등 확인에 불필요한 내용을 가린 뒤 제출합니다.

4교사: 맞춤형 학습 배정

길드 목록 → 길드 카드 → 길드원 관리

개인·그룹·전체 및 향후 가입자에게 설정할 수 있습니다.

적용 대상

  • 개별 학생 직접 선택
  • 지원 필요·성장 중·안정 그룹
  • 전체 길드원
  • 전체 길드원·향후 가입자 기본값

학습 내용

  • 여러 단어팩 중복 선택
  • 3~6학년 수준별 단어팩
  • 교육과정 검토 단어팩
  • 6개 문제 유형 중복 선택
배정 예: 지원 필요 학생에게 하위 수준·객관식 중심, 안정 학생에게 상위 수준·영어 단답식과 철자 순서 맞추기를 추가합니다.

6교사: 오답 시련

길드 전체 누적 오답을 문제로 만들고 유형을 단어별로 검토합니다.

항목규칙

7학생: 영단어 학습과 채점

퀴즈 전투가 학습의 중심이며 성장 기능은 정답 보상과 연결됩니다.

6가지 문제 유형

뜻 찾기빈칸 넣기영어 찾기발음 듣기철자 순서영어 단답

입력 원칙

  • 철자 순서 글자는 소문자로 표시
  • 영어 표시는 첫 글자 대문자·나머지 소문자
  • 띄어쓰기 차이는 무시
  • 한글·숫자 오입력은 오답 처리하지 않고 안내
  • 잘못 입력한 부분을 지우고 계속 작성
숙련 단어: 정답 10회 이상·누적 정답률 80% 이상을 달성하면 숙련으로 표시됩니다.

8학생: 성장과 수집 기능

대장간·잠재력

골드로 장비를 강화하고 잠재력 옵션을 연구합니다.

펫·유물

소환수 효과는 누적되며 유물은 전투·학습 효과를 제공합니다.

마법 스킬

정복 단어로 획득·성장하고 보스전에서 직접 사용합니다.

차원 영웅

외형 등급 장착 효과와 등급별 도감 효과를 모읍니다.

길드 상점

길드 코인으로 외형·강화 보호·재화 교환을 이용합니다.

길드 효과

길드 기여 포인트를 투자해 모든 길드원이 공유하는 효과를 성장시킵니다.

확률 안내: 외형·도감과 길드 효과의 행운 보너스는 잠재력·유물·마법 카드 확률에 합산되며 차원 영웅 소환 확률은 고정입니다.

  • 오답 시련과 배정 학습
  • 길드 코인 상점

  • 공동 길드 효과 투자

월드보스

  • 전 학년 공유 체력
  • 180초 실시간 퀴즈 전투
  • 장착 4종 스킬 직접 시전
  • 당일 이탈 기록 이어하기
  • 보스별 고유 공격 패턴

리치의 사령의 저주 예시

스킬을 봉인하고 해제 퀴즈를 요구하는 고유 패턴입니다. 단어·뜻 4지선다, 철자 순서 맞추기, 빈칸 넣기 중 무작위 문제가 나오며 해제 퀴즈 동안에는 월드보스 시간이 멈춥니다. 봉인이 풀리고 쿨타임이 아니라면 스킬이 즉시 시전됩니다.

보스 규칙은 시즌 조정에 따라 바뀔 수 있으므로 참전 화면의 고유 패턴 설명을 먼저 확인합니다.

10수업 운영·FAQ·계정 삭제

첫 차시 권장 흐름

  1. 교사: 길드·기본 학습 설정
  2. 학생: 닉네임 계정 생성
  3. 학생: 길드 가입·Google 연동
  4. 10~20분 퀴즈 전투
  5. 교사: 참여·정답률 확인
  6. 다음 차시 오답 시련

학습 습관

  • 하루 10~30분 범위에서 꾸준히
  • 한 문제 유형에 치우치지 않기
  • 오답·숙련 기록 확인
  • 게임 재화보다 학습 목표 우선

자주 묻는 문제

문제조치
Google 이어하기가 다른 용사를 엶연동했던 정확한 Google 계정인지 확인
개별 설정이 반영되지 않음교사 저장 완료·선택 학생 확인 후 학생 새로고침/재실행
길드 초대가 안 됨영문·숫자 6자리와 코드 갱신 여부 확인
월드보스 이어하기가 안 보임같은 날짜·같은 계정인지 확인. 날짜가 바뀌면 이전 피해로 정산
입력 중 한글·숫자를 누름오답 처리되지 않으므로 해당 부분을 지우고 계속 입력

탈퇴·내보내기·삭제

  • 길드 탈퇴/내보내기: 길드 소속만 해제되고 학생 개인 학습·게임 기록은 유지됩니다.
  • 길드 폐쇄: 길드 연결과 길드 데이터가 삭제되지만 학생 개인 기록은 유지됩니다.
  • 계정 삭제: 설정의 계정 삭제 안내에 따라 인증 계정과 관련 게임·학습 데이터를 삭제합니다.
상세한 처리·보관·삭제 내용은 서비스의 개인정보 처리·계정 삭제 안내에서 확인합니다.
