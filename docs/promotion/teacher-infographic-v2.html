TEACHER VALUE

수업 운영은 선명하게, 학습 경험은 즐겁게

01

학생별 맞춤 배정

누적 단어팩 1개와 6개 문제 유형을 개인·그룹·전체에 설정하고, 선택팩 안의 미해결·직전·현재 단계 비중을 자동 조절합니다.

02

학습 데이터 분석

최근 참여와 정답률, 유형별 성취, 반복 오답을 확인해 지원 학생과 수업 제안을 찾습니다.

03

오답 기반 시련

길드 누적 오답의 유형을 검토해 시련을 배포하고 최대 3회 재도전으로 다시 학습합니다.

04

협동 학습 동기

길드 기여, 성장, 수집, 월드보스를 통해 개인 학습을 함께 달성하는 목표로 연결합니다.

교사 운영 흐름복잡한 설치 없이 브라우저에서 시작
1. 교사 등록Google 로그인·재직 확인
2. 길드 생성·초대6자리 코드·QR·링크
3. 학습 설정단어팩·문제 유형 배정
4. 분석·피드백참여·정답·오답·시련
