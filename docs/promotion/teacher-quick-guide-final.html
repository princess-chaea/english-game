교사 등록

  1. 교사 로그인을 누릅니다.
  2. Google로 교사 로그인을 선택합니다.
  3. 학교 검색 결과에서 재직 학교를 고릅니다.
  4. 교사 이름과 최근 1개월 이내 재직증명서를 제출합니다.
  5. 검토 완료 뒤 교사 길드 본부를 이용합니다.
주민등록번호·주소·전화번호 등 불필요한 정보는 가린 뒤 제출하세요.

길드 개설·학생 초대

  1. 길드 창설·참여에서 새 길드를 만듭니다.
  2. 길드 이름, 표시 이미지, 기본 단어 수준을 정합니다.
  3. 길드 및 초대관리에서 학생용 6자리 영문·숫자 코드, QR 또는 링크를 공유합니다.
  4. 공동 관리자는 별도의 관리자 초대 코드로 참여합니다.
학생용과 관리자용 코드는 서로 다릅니다. 노출되면 갱신하세요.

4데이터 분석과 오답 시련

길드 정보에서 확인

  • 오늘·최근 7일 참여
  • 전체 정답률과 성취 분포
  • 최근 14일 학습량
  • 문제 유형별 강점·약점
  • 반복 오답과 수업 설계 제안

시련으로 재학습

  1. 길드 누적 오답을 확인합니다.
  2. 5·10·15·20문제를 선택합니다.
  3. 문제 유형과 단어별 구성을 검토합니다.
  4. 검토 완료 · 시련 배포를 누릅니다.
분석 순서보는 내용다음 조치
참여최근 학습·미접속참여 안내
정확도전체·유형별 차이유형 비율 조정
단어반복해서 틀린 단어단어팩 재배정·시련
추이최근 학습 변화다음 차시 계획
시련 규칙: 전체 문제는 최대 3회 도전합니다. 객관식 힌트는 오답 2개를 지우고, 입력형 힌트는 첫 글자와 영문 글자 수를 알려줍니다.

6첫 차시 운영과 빠른 문제 해결

첫 수업 20분 예시

  1. 수업 전 길드·기본 단어팩 준비
  2. 0~5분 학생 가입과 길드 참여
  3. 5~17분 퀴즈 전투와 성장 탐색
  4. 17~20분 학습·길드 기록 확인
  5. 수업 뒤 참여·정답률·오답 분석
  6. 다음 차시 5문제 시련으로 재학습

학생에게 먼저 말할 것

  • 실명 대신 별명을 사용합니다.
  • 퀴즈 정답이 성장과 길드 활동에 반영됩니다.
  • 틀린 단어는 다시 나오고 시련으로 복습합니다.
  • Google 연동은 현재 기록을 이어가기 위한 기능입니다.
