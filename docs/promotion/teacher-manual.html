VOCA HERO!란?

영어 단어 퀴즈의 정답을 캐릭터 성장·수집·강화·길드 협동·월드보스에 연결한 웹 기반 학습 게임입니다. 교사는 학생별로 누적 단어팩 하나와 여러 문제 유형을 배정하고 참여·정답·오답·숙련 데이터를 확인해 오답 기반 시련을 배포할 수 있습니다.

교사 등록

  1. 첫 화면에서 교사 로그인을 선택합니다.
  2. Google로 교사 로그인을 누릅니다.
  3. 학교정보 API 검색 결과에서 학교를 선택합니다.
  4. 교사 이름과 최근 1개월 이내 재직증명서를 제출합니다.
  5. 자동 확인과 최종 검토가 끝나면 학교 길드 기능을 사용합니다.

2길드 만들기와 초대

새 길드 만들기

길드 창설·참여 → 새 길드 만들기

  1. 길드 이름 입력
  2. 교사용 태그 입력(선택)
  3. 기본 단어 수준 초등 3학년~고등 3학년 선택
  4. 길드 만들기

처음 만든 교사는 길드 마스터가 됩니다.

공동 관리자 참여

길드 창설·참여 → 공동 관리자로 참여

  • 같은 학교의 인증된 교사만 참여
  • 6자리 코드 또는 학교 길드 가입 신청
  • 마스터 위임·관리자 내보내기 지원

학생 초대

내 길드 → 길드 카드 → 길드 및 초대관리

  1. 길드원 초대 코드·QR·링크를 엽니다.
  2. 코드, QR 또는 링크를 학생에게 전달합니다.
  3. 학생은 닉네임 계정을 만든 뒤 길드에 참여합니다.
초대 코드
영문 대문자와 숫자가 섞인 6자리입니다. 외부에 노출되면 새 코드로 교체하세요.

3학생별 학습 설정

내 길드 → 길드원 관리

설정 순서

  1. 적용 학생을 직접 또는 그룹으로 선택합니다.
  2. 초등 3학년~고등 3학년 누적 단어팩 하나를 선택합니다.
  3. 사용할 문제 유형을 선택합니다.
  4. 선택한 길드원에게 적용 또는 전체 길드원·향후 가입자에 적용을 누릅니다.

6가지 문제 유형

뜻 찾기빈칸 넣기영어 단어 찾기발음 듣고 뜻 찾기철자 순서 맞추기영어 단답식
선택 규칙: 뜻 찾기는 기본 유형입니다. 누적 단어팩은 하나만, 문제 유형은 여러 개 선택합니다.
교육과정 누적팩: 2022 개정 영어과 기본 어휘 3,000개를 바탕으로 추출 표제어 3,001개를 보존했습니다. 초3~고3에서 하⊂중⊂상, 다음 학년은 이전 학년 단어를 포함합니다.
적응형 경로: 미해결 오답은 한 번 이상 틀리고 연속 정답 3회 미만 또는 정답률 80% 미만인 단어입니다. 선택팩 누적 풀이가 8회 이상이면서 정답률 75% 미만이거나, 미해결이 3개 이상이거나, 미해결 누적 오답 합계가 4회 이상이면 문항 보충 모드가 켜집니다. 후보가 모두 있을 때의 기본 목표는 미해결/직전/현재 단계 순으로 보충 55/30/15%, 평소 20/20/60%이며, 선택 그룹에 직전 문항과 다른 후보가 없으면 가능한 다음 그룹으로 재배분합니다. 모두 선택팩 안에서만 움직이며 더 낮은 학년은 교사가 수동 지정합니다.

숙련 기준
정답 10회 이상이면서 누적 정답률 80% 이상인 단어입니다.
화면과 판정: 학생 리포트는 미해결 오답·직전 누적단계 복습·현재 단계 단어의 기본 목표 비중과 후보 수를 표시합니다. 지원 그룹과 문항 보충 경로는 별도 판정입니다. PC에서는 상단 접기·펼치기로 본부 머리글과 큰 로고·태그를 줄일 수 있고 모바일·터치 화면은 항상 펼칩니다.

확인 순서 제안

  1. 참여: 최근 7일 학습 여부

  3. 단어: 반복해서 틀리는 단어
  4. 조치: 설정 조정 또는 시련 배포

5오답 시련 운영

내 길드 → 시련

  1. 길드 전체 누적 오답을 확인합니다.
  2. 5·10·15·20문제 중 문제 수를 선택합니다.
  3. 자동 배정 유형을 단어별로 검토·변경합니다.
  4. 검토 완료 · 시련 배포를 누릅니다.

초대 코드 오류

시련 생성 불가

뜻이 등록된 누적 오답이 5개 이상인지 확인합니다.

모바일 화면이 작음

가로 모드에서 확대하거나 PC·태블릿을 사용합니다.

첫 수업 운영안

  1. 수업 전: 교사 등록·길드 생성·기본 단어팩
  2. 첫 5분: 학생 계정 생성·길드 가입
  3. 10~20분: 퀴즈 전투·성장 탐색
  4. 수업 후: 참여·정답률·지원 학생 확인
  5. 다음 차시: 누적 오답 5문제 시련
