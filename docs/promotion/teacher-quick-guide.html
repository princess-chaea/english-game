교사 등록

  1. 교사 로그인을 누릅니다.
  2. Google로 교사 로그인을 선택합니다.
  3. 학교정보 검색 결과에서 학교를 선택합니다.
  4. 교사 이름과 최근 1개월 이내 재직증명서를 제출합니다.
  5. 검토가 끝나면 학교 길드 본부를 이용합니다.
업로드 전 주민등록번호·주소·전화번호 등 확인에 필요하지 않은 정보는 가려 주세요.

길드 만들기·참여

  1. 길드 창설·참여를 엽니다.
  2. 길드 이름, 교사용 태그(선택), 기본 단어 수준을 설정합니다.
  3. 처음 만든 교사는 길드 마스터가 됩니다.
  4. 같은 학교의 인증된 교사만 공동 관리자로 참여할 수 있습니다.
학생 초대: 길드 및 초대관리에서 영문·숫자 6자리 코드, QR 또는 링크를 전달합니다.

학습 내용 고르기

누적 단어팩 하나와 문제 유형 여러 개를 선택할 수 있습니다.

뜻 찾기빈칸 넣기영어 찾기발음 듣기철자 순서영어 단답

뜻 찾기는 기본 유형입니다. 단어팩은 2022 개정 영어과 기본 어휘 3,000개 기반의 표제어 3,001개를 초3~고3 하⊂중⊂상으로 누적합니다.

자동 경로: 문항 보충은 선택팩 누적 풀이가 8회 이상이면서 정답률 75% 미만이거나, 미해결이 3개 이상이거나, 미해결 오답 합계가 4회 이상이면 켜집니다. 후보가 모두 있을 때 미해결/직전/현재 단계의 기본 목표는 보충 55/30/15%, 평소 20/20/60%이며 빈 그룹은 가능한 다음 그룹으로 재배분합니다. 더 기초부터 시작할 학생은 교사가 이전 학년 누적팩을 직접 지정하고, 객관식 중심 문제 유형을 배정합니다. 길드원 정보의 학생 리포트에서 실제 배정팩·배정 출처, 일반/문항 보충 경로, 기본 목표 비중과 진입 근거를 확인합니다. PC 길드 상세에서는 상단을 접어 리포트 공간을 넓힐 수 있고, 모바일·터치 화면은 항상 펼칩니다.

  • 문제 유형별 풀이·정답률
  • 반복 오답과 수업 설계 제안

시련에서 실행

  1. 길드 공통 문항 또는 학생별 개별 맞춤 선택
  2. 개별 맞춤은 전체·지원 필요·성장 중·안정 일괄 선택
  3. 5·10·15·20문제와 학생별 구성을 미리보기
  4. 확인 뒤 새 시련 배포

4한 차시 운영 예시와 문제 해결

첫 수업 20분 예시

  1. 수업 전 길드·기본 단어팩 준비
  2. 0~5분 학생 가입과 길드 참여
  3. 5~17분 퀴즈 전투와 성장 탐색
  4. 17~20분 길드 기여·학습 기록 확인
  5. 수업 후 참여·정답률·오답 분석
  6. 다음 차시 5문제 시련으로 재학습

학생에게 먼저 말할 것

  • 실명 대신 닉네임 사용
  • 퀴즈 정답이 게임 성장과 길드 활동에 반영
  • 틀린 단어는 다시 출제되고 시련에 활용 가능
  • Google 연동은 기록 이어하기용
