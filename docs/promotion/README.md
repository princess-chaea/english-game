# VOCA HERO 교사용 홍보·운영 자료

현재 서비스 코드와 개인정보 안내를 기준으로 2026-08-12에 작성한 자료입니다.

## 산출물

- `teacher-infographic.html`: A4 1장 교사용 인포그래픽
- `teacher-manual.md`: 수정하기 쉬운 교사용 매뉴얼 원본
- `teacher-manual.html`: 인쇄·PDF 배포용 교사용 매뉴얼
- `student-quick-start.html`: 학생에게 배포하는 A4 1장 빠른 시작 안내
- `assets/teacher-infographic-hero.png`: 인포그래픽 대표 일러스트

## 출력 권장

- 브라우저에서 HTML을 열고 인쇄 → PDF 저장
- 용지 A4, 배율 100%, 배경 그래픽 켜기
- 인포그래픽은 여백 없음, 매뉴얼은 기본 여백 사용

## 내용 관리 원칙

게임 규칙이나 교사 화면이 바뀌면 먼저 `teacher-manual.md`를 수정하고 인포그래픽의 핵심 문구가 여전히 정확한지 확인합니다.
