# Voca Hero! 실제 화면 중심 안내자료

기준일: 2026-08-21
대상: 초등 영어 수업 교사·학생·보호자·학교 관리자

## 최종 상세판

1. `teacher-quick-guide-detailed.pdf` — 교사 퀵가이드 34쪽
2. `student-quick-guide-detailed.pdf` — 학생 퀵가이드 45쪽
3. `integrated-manual-detailed.pdf` — 공통·교사·학생 통합 매뉴얼 75쪽
4. `core-promotion-detailed.pdf` — 교사 대상 핵심 홍보자료 2쪽

같은 이름의 HTML은 수정 가능한 16:9 발표 원본입니다. `detailed-deck.css`와 `detailed-deck-renderer.js`가 공통 디자인을 담당합니다.

## 화면 용어

- **학급(길드) 전체 리포트**: 실제 교사 화면의 `길드 정보` 탭
- **학생별 개별 리포트**: 실제 교사 화면의 `길드원 정보` 탭에서 학생 선택 후 `분석 보기`
- **수업 설계 제안**: `길드 정보` 안의 실제 기능명
- **맞춤 배정**: `길드원 관리` 탭
- **공동 관리**: `길드 및 초대관리` 탭의 공동 관리자 초대·권한 기능

설명용 용어와 실제 탭 이름을 함께 적어 교사가 바로 같은 화면을 찾을 수 있게 했습니다.

## 다룬 기능

- 교사: 가입·Google 인증·재직 검토·길드 선택·학급 전체 분석·학생별 분석·문제 유형/단어팩 배정·시련·학생/공동 관리자 초대
- 학생 학습: 가입·Google 연결·문제 6종·입력 규칙·단어 서고·오답 복습
- 성장: 스테이지·일반 보스·대장간·잠재력·장신구·펫·스킬·유물·차원 영웅
- 협동: 월드보스 3종·이어하기·주간 보상·길드 6개 탭·길드 상점·길드 효과
- 기록: 내 영웅 정보·학습 리포트·명예의 전당·랭킹·학습/성장/협동 칭호

## 2026-08-12 기능 설명 보강

- 홍보자료의 `7개 탭`, `6개 길드 탭` 같은 단순 수량 문구를 학급 리포트·맞춤 배정·오답 시련·성장·협동의 실제 기능과 수업 활용 문장으로 교체했습니다.
- 유형별 학습 기록은 `1/1` 비율 대신 `뜻 찾기 정답 3회`처럼 자연수 횟수로 설명합니다.
- 정복·숙련 기준, 성취 그룹 판정, 학생 화면 배정 반영 시점, 시련 문제 수·힌트·재도전·보상을 명시했습니다.
- 길드 포인트·코인 획득 경로, 25P씩 길드 효과에 기여하는 레벨 경험치 구조, 상점 가격·적용 횟수·교환량을 명시했습니다.
- 차원 영웅 고정 확률과 행운 미적용, 유물 신화 확정 소환의 신규·기존·6성 중복 처리, 소환 중 연속 클릭 차단 규칙을 추가했습니다.
- 화면 캡처는 `captures/`의 같은 파일명을 원본으로 사용합니다. UI가 바뀌면 캡처를 먼저 갱신하고 HTML·PDF·PPTX를 다시 출력해 설명과 화면을 같은 버전으로 유지합니다.

## 2026-08-21 교사 리포트 보강

- 길드원 정보의 학생 리포트에서 배정 누적팩·배정 출처, 실제 일반/문항 보충 경로, 세 문항 그룹의 기본 목표 비중·후보 수와 보충 진입 근거를 확인하도록 캡처와 설명을 갱신했습니다.
- 데스크톱 길드 상세 화면은 상단 접기·펼치기로 본부 머리글과 큰 길드 로고·태그를 줄일 수 있으며, 길드명·5개 탭·리포트는 유지합니다. 같은 브라우저에 상태를 저장하고 모바일·터치 화면은 항상 펼칩니다.

## 재출력

Chrome에서 HTML을 열고 인쇄할 때 가로 방향, 배율 100%, 머리글/바닥글 끄기, 배경 그래픽 켜기를 사용합니다. 현재 PDF는 16:9 슬라이드 규격으로 출력되어 있습니다.

PDF 파일은 저장소 용량 정책상 Git에서 제외되지만 이 작업 폴더에는 생성되어 있습니다. HTML·CSS·JS·캡처 원본은 Git에 포함됩니다.

## 개인정보

캡처에는 안내용 별명과 게임 기록만 사용합니다. 학생 학교·실명·학번은 수집·표시하지 않는 서비스 원칙을 문서에도 동일하게 적용합니다.
