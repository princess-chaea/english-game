학생별 맞춤 배정

누적 단어팩 1개와 6개 문제 유형을 개인·그룹·전체에 설정합니다. 선택팩 안에서는 미해결·직전·현재 단계 비중이 자동 조절됩니다.

����

학습 데이터 확인

최근 참여, 정답률, 숙련 단어, 문제 유형별 성취와 단어별 맞음·틀림 기록을 확인하고 지원 필요 학생을 찾습니다.

����

오답 기반 시련

길드 누적 오답에서 문제를 만들고 유형을 검토해 배포합니다. 학생은 힌트와 최대 3회 도전으로 틀린 단어를 다시 학습합니다.

����️

협동 학습 동기

길드 기여, 랭킹, 성장, 수집, 월드보스를 통해 개인 학습을 함께 달성하는 목표로 연결합니다.

교사 운영 흐름

복잡한 설치 없이 브라우저에서 시작
1. 교사 등록Google 로그인과 재직 확인
2. 길드 생성·초대6자리 코드·QR·링크 제공
3. 학습 설정단어팩·문제 유형 개별 배정
4. 분석·피드백참여·정답·오답·시련 확인
학생 개인정보는 최소한으로

새 학생 계정에는 실명·학교·반·번호를 저장하지 않습니다. 교사는 길드원의 닉네임과 학습·게임 성취 데이터만 확인합니다.
