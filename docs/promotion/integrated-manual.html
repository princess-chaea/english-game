한 문장으로 이해하기

VOCA HERO!는 영단어 퀴즈의 정답과 반복 학습을 캐릭터 성장·수집·길드 협동에 연결하고, 교사가 학생별 학습 내용을 배정하고 성취를 분석할 수 있는 웹 기반 영어 학습 게임입니다.

2공통: 계정과 개인정보

새 학생 계정

  • 실명 대신 한글·숫자 2~12자의 닉네임
  • 학습할 영단어 학년 선택
  • 학습 기록 저장 안내 필수 확인
  • 전체 랭킹 공개는 선택

새 계정에는 학교명·실명·반·번호·주소·전화번호를 저장하지 않습니다.

Google 계정 연동

  • 현재 용사 기록을 Google 계정에 연결
  • 다른 기기에서 같은 기록 이어하기
  • 연동 후 첫 화면의 Google 이어하기 사용
  • 필요하면 설정에서 연결 해제

연동은 새 용사를 추가로 만드는 기능이 아닙니다.

서비스에서 처리하는 정보

학생교사
인증 UID, 닉네임, 학습 학년, 게임 진행·학습 기록과 설정Google 인증, 교사 이름, 학교명, 재직 확인 자료와 길드 관리 기록
교사에게 길드 닉네임과 학습·게임 성취가 표시됩니다.이름·학교는 재직 확인과 같은 학교 길드 연결에 사용됩니다.
닉네임 주의: 이름·학교·학년반번호 같은 개인정보나 부적절한 표현을 넣지 않습니다.

기존 기록 가져오기

업데이트 이전 기록이 있는 경우 가입 화면의 기존 게임 기록 가져오기를 이용합니다. 예전 학교·반·번호·이름은 기존 기록을 한 번 찾는 용도로만 사용하며 새 계정에는 저장하지 않습니다.

3교사: 가입·길드·초대

교사 로그인첫 화면 왼쪽 위
재직 확인학교·이름·증명서
길드 생성기본 단어 수준
학생 초대코드·QR·링크

가입

  1. Google로 교사 로그인
  2. 학교정보 검색 결과 선택
  3. 교사 이름 입력
  4. 최근 1개월 이내 재직증명서 제출
  5. 검토 후 학교 길드 본부 이용

길드와 권한

  • 처음 만든 교사: 길드 마스터
  • 같은 학교 인증 교사: 공동 관리자 참여 가능
  • 마스터 위임·공동 관리자 내보내기
  • 학생용과 관리자용 초대 코드는 별도

실제 초대·권한 관리 화면. 식별 정보는 자료용 예시 이름으로 익명화했습니다.

학생은 게임 안 길드 가입에서 QR을 직접 촬영하거나 영문·숫자 6자리 코드를 입력합니다. 노출되면 새 코드로 갱신합니다.
재직증명서는 주민등록번호·주소·전화번호 등 확인에 불필요한 내용을 가린 뒤 제출합니다.

적용 대상

  • 개별 학생 직접 선택
  • 지원 필요·성장 중·안정 그룹
  • 전체 길드원
  • 전체 길드원·향후 가입자 기본값

학습 내용

  • 누적 단어팩 하나 선택
  • 초3~고3 하·중·상 누적 단계
  • 2022 개정 영어과 기본 어휘 3,000개 기반·표제어 3,001개 보존
  • 6개 문제 유형 복수 선택
적응형 경로: 문항 보충 모드는 선택팩 누적 풀이가 8회 이상이면서 정답률 75% 미만이거나, 미해결이 3개 이상이거나, 미해결 누적 오답 합계가 4회 이상이면 켜집니다. 후보가 모두 있을 때 미해결/직전/현재 단계의 기본 목표는 보충 55/30/15%, 평소 20/20/60%이며, 선택 그룹에 직전 문항과 다른 후보가 없으면 가능한 다음 그룹으로 재배분합니다. 더 낮은 학년은 교사가 해당 누적팩을 직접 지정합니다.

7학생: 영단어 학습과 채점

퀴즈 전투가 학습의 중심이며 성장 기능은 정답 보상과 연결됩니다.

6가지 문제 유형

뜻 찾기빈칸 넣기영어 찾기발음 듣기철자 순서영어 단답

입력 원칙

  • 철자 순서 글자는 소문자로 표시
  • 영어 표시는 첫 글자 대문자·나머지 소문자
  • 띄어쓰기 차이는 무시
  • 한글·숫자 오입력은 오답 처리하지 않고 안내
  • 잘못 입력한 부분을 지우고 계속 작성
숙련 단어: 정답 10회 이상·누적 정답률 80% 이상을 달성하면 숙련으로 표시됩니다.

8학생: 성장과 수집 기능

대장간·잠재력

골드로 장비를 강화하고 잠재력 옵션을 연구합니다.

펫·유물

소환수 효과는 누적되며 유물은 전투·학습 효과를 제공합니다.

마법 스킬

퀴즈 FP로 캡슐을 열어 획득·성장하고 최대 4장을 장착해 사용합니다.

차원 영웅

외형 등급 장착 효과와 등급별 도감 효과를 모읍니다.

길드 상점

길드 코인으로 외형·강화 보호·재화 교환을 이용합니다.

길드 효과

길드 기여 포인트를 투자해 모든 길드원이 공유하는 효과를 성장시킵니다.

스킬 핵심: 퀴즈 FP로 캡슐을 열며 1/10/100회는 50/450/4,500 FP, 장착은 최대 4장입니다. 후보가 있을 때 신규/성장/정수 기본 비중은 40/50/10%이고, 카드 기본 등급은 일반/희귀/영웅/전설/신화 75/18/5/1.95/0.05%, 티어는 T3/T2/T1 70/25/5%입니다. 상위 등급은 성급과 현재 성장 바 비율을 보존하고 좋은 티어를 즉시 적용하며, 같은·하위 등급은 성장 1칸입니다. 6성 뒤 T3→T2→T1, T1 6성이 MAX입니다.
합성·분해·피해: 합성은 정확히 3장입니다. 동일 등급 승급률은 20% + 합산 누적 별×10%p + 성장 바 진행률 합×5%p(최대 15%p) + 연속 실패×15%p, 전체 최대 95%입니다. 혼합은 등급 1/3/9/27 × 티어 1/1.1/1.2 × (1+누적 별×0.15) × (1+성장 바 비율×0.15)의 평균이며 최고 재료 등급을 넘지 않고 결과 별·성장 바는 0입니다. 신화는 합성 불가지만 분해할 수 있습니다. 표시 지수는 등급 5/10/20/40/70 × 티어 × 별 계수를 반올림한 5~311이며 실제 피해는 공격력·DPS·보너스·퀴즈 피해 하한·보스 보정으로 계산되고 일반 보스 단일 스킬은 최대 체력 10%가 상한입니다.

리치의 사령의 저주 예시

스킬을 봉인하고 해제 퀴즈를 요구하는 고유 패턴입니다. 단어·뜻 4지선다, 철자 순서 맞추기, 빈칸 넣기 중 무작위 문제가 나오며 해제 퀴즈 동안에는 월드보스 시간이 멈춥니다. 봉인이 풀리고 쿨타임이 아니라면 스킬이 즉시 시전됩니다.

보스 규칙은 시즌 조정에 따라 바뀔 수 있으므로 참전 화면의 고유 패턴 설명을 먼저 확인합니다.
