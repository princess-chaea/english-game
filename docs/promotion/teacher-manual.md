# VOCA HERO! 교사용 운영 매뉴얼

> 기준 버전: 2026-08-20
> 접속 주소: https://english-game-sage.vercel.app/

## 1. VOCA HERO!란?

VOCA HERO!는 영어 단어 퀴즈의 정답을 캐릭터 성장·수집·강화·길드 협동·월드보스와 연결한 웹 기반 학습 게임입니다. 교사는 학생별로 누적 단어팩 하나와 여러 문제 유형을 배정하고, 길드 전체 및 개인의 참여·정답·오답·숙련 데이터를 확인하여 오답 기반 시련을 배포할 수 있습니다.

### 교사 기능 한눈에 보기

- 길드 생성 및 같은 학교 공동 관리자 운영
- 학생용·공동 관리자용 6자리 영문/숫자 초대 코드, QR, 링크
- 학생별·선택 그룹별·전체에 누적 단어팩 하나와 여러 문제 유형 배정
- 참여, 스테이지, 길드 기여, 정답률, 숙련 단어 확인
- 문제 유형별 성취와 단어별 맞음·틀림 기록 분석
- 지원 필요·성장 중·안정 학생 분류
- 길드 누적 오답을 이용한 5~20문제 시련 제작

## 2. 시작 전 확인

- 최신 Chrome, Edge 또는 모바일 브라우저를 권장합니다.
- 교사 기능은 Google 로그인과 재직 확인 후 사용할 수 있습니다.
- 재직증명서는 현재 날짜 기준 1개월 이내 발급본을 사용합니다.
- 업로드 전 주민등록번호, 주소, 전화번호 등 불필요한 개인정보를 가립니다.

## 3. 교사 등록

1. 첫 화면에서 **교사 로그인**을 선택합니다.
2. **Google로 교사 로그인**을 누릅니다.
3. **교사 등록**에서 학교정보 API 검색 결과의 학교를 선택합니다.
4. 교사 이름과 최근 1개월 이내 재직증명서를 제출합니다.
5. 자동 확인과 최종 검토가 끝난 뒤 학교 길드 기능을 사용합니다.

교사 이름과 학교는 재직 확인, 같은 학교 길드 연결, 관리 권한 표시에만 사용합니다.

## 4. 길드 만들기와 참여

### 새 길드 만들기

1. **길드 창설·참여**로 이동합니다.
2. 길드 이름과 선택 사항인 교사용 길드 태그를 입력합니다.
3. 기본 단어 수준을 초등 3학년~고등 3학년에서 선택합니다.
4. **길드 만들기**를 누릅니다.

길드를 처음 만든 교사는 길드 마스터가 됩니다. 태그는 교사 화면의 길드 구분에 사용되며 학생에게 표시되지 않습니다.

### 공동 관리자로 참여

- 같은 학교의 인증된 교사만 공동 관리자가 될 수 있습니다.
- 초대받은 공동 관리자 코드를 입력하거나 같은 학교 길드에서 가입을 신청합니다.
- 길드 마스터는 공동 관리자를 내보내거나 마스터 권한을 위임할 수 있습니다.

## 5. 학생 초대

1. **내 길드**에서 길드 카드를 선택합니다.
2. **길드 및 초대관리**를 엽니다.
3. **길드원 초대 코드·QR·링크**를 선택합니다.
4. 학생에게 코드, QR 또는 링크 중 하나를 전달합니다.
5. 학생은 계정을 만든 뒤 길드 메뉴에서 참여합니다.

초대 코드는 영문 대문자와 숫자가 섞인 6자리입니다. 학생은 실명이나 학번 대신 닉네임으로 참여합니다. 코드가 외부에 노출되면 초대 화면에서 새 코드로 교체합니다.

## 6. 단어팩과 문제 유형 배정

1. 길드 관리 화면에서 **길드원 관리**를 선택합니다.
2. 적용할 학생을 직접 선택하거나 **지원 필요·성장 중·안정** 그룹을 선택합니다.
3. 학생에게 적용할 누적 단어팩 하나를 선택합니다.
4. 사용할 문제 유형을 선택합니다.
5. **선택한 길드원에게 적용** 또는 **전체 길드원·향후 가입자에 적용**을 누릅니다.

### 지원 그룹 기준

- 지원 필요: 학습 미시작, 7일 이상 미접속 또는 10회 이상 학습하면서 정답률 40% 미만
- 안정: 최근 7일 참여, 10회 이상 학습, 정답률 70% 이상
- 성장 중: 두 기준 사이

### 제공 문제 유형

1. 뜻 찾기
2. 빈칸 넣기
3. 영어 단어 찾기
4. 발음 듣고 뜻 찾기
5. 철자 순서 맞추기
6. 영어 단답식

뜻 찾기는 기본 문제 유형으로 유지됩니다. 단어팩은 누적팩 하나만 선택하고 문제 유형은 여러 개 선택할 수 있습니다. 저장된 설정은 학생이 다시 접속할 때도 유지됩니다.

### 교육과정 기반 나선형 누적 단어팩

단어팩은 **2022 개정 영어과 교육과정 기본 어휘 목록**을 바탕으로 난이도와 사용 빈도를 반영해 초등 3학년부터 고등 3학년까지 나선형으로 확장합니다. 교육과정 문서의 명칭은 '기본 어휘 3,000개'이지만, 앱은 원문에서 추출·중복 정리한 표제어 3,001개를 누락 없이 보존합니다.

- 같은 학년에서는 **하 ⊂ 중 ⊂ 상**, 다음 학년은 앞 학년까지 포함하는 누적 구조입니다.
- 예: 초등 6학년 중(550개)은 초등 6학년 하(500개)를 포함합니다.
- 기본 권장은 해당 학년의 **중** 단계입니다.
- 학생 수준을 낮춰 시작하려면 교사가 더 낮은 학년·단계의 누적팩을 직접 지정합니다. 자동 경로가 선택팩 바깥의 더 낮은 학년으로 내려가지는 않습니다.

| 학년 | 하 | 중 | 상 |
|---|---:|---:|---:|
| 초등 3 | 50 | 100 | 150 |
| 초등 4 | 200 | 250 | 300 |
| 초등 5 | 350 | 400 | 450 |
| 초등 6 | 500 | 550 | 600 |
| 중등 1 | 700 | 800 | 900 |
| 중등 2 | 1,000 | 1,100 | 1,200 |
| 중등 3 | 1,300 | 1,400 | 1,500 |
| 고등 1 | 1,600 | 1,700 | 1,800 |
| 고등 2 | 1,934 | 2,067 | 2,200 |
| 고등 3 | 2,467 | 2,734 | 3,001 |

### 선택 팩 내부 적응형 문항 경로

일반 퀴즈는 선택한 누적팩 안에서 학생의 풀이 기록에 따라 출제 비중을 조절합니다.

- **미해결 오답**: 한 번 이상 틀렸고, 연속 정답이 3회 미만이거나 누적 정답률이 80% 미만인 단어
- **보충 경로 진입**: 선택팩 풀이가 8회 이상이면서 정답률 75% 미만, 미해결 오답이 3개 이상, 또는 미해결 오답의 누적 오답 합계가 4회 이상일 때
- **보충 경로 비중**: 미해결 오답 55% · 직전 단계 30% · 현재 단계 15%
- **일반 경로 비중**: 미해결 오답 20% · 직전 단계 20% · 현재 단계 60%
- 후보가 비면 다른 그룹으로 비중을 넘기며, 가능하면 직전 문항 반복을 피합니다. 미해결 오답 안에서는 많이 틀린 단어가 더 자주 선택됩니다.

여기서 직전 단계와 현재 단계도 모두 선택한 누적팩 안의 단어입니다. 학생이 학년 기초부터 다시 학습해야 한다면 교사가 해당 학생에게 이전 학년 누적팩을 수동 지정합니다.

## 7. 학습 데이터 확인

### 길드 정보

- 길드원 수와 학습 참여
- 길드 기여, 정복·숙련 단어, 길드 랭킹
- 길드 정답률
- 문제 유형별 풀이 횟수와 정답률
- 가장 많이 틀린 단어

### 길드원 정보

학생 카드를 선택하면 다음 내용을 확인합니다.

- 최근 학습일, 스테이지, 길드 기여
- 전체 정답률과 숙련 단어 수
- 최근 30일 학습량과 정답률
- 월별 학습 패턴과 시련 응시
- 문제 유형별 성취
- 단어별 맞음·틀림·유형별 학습 기록

숙련 단어는 정답 10회 이상이면서 누적 정답률 80% 이상인 단어입니다.

## 8. 오답 시련 운영

1. 길드 관리의 **시련** 탭을 엽니다.
2. 길드 전체 누적 오답을 확인합니다.
3. 5·10·15·20문제 중 시련 문제 수를 선택합니다.
4. 자동 배정된 문제 유형을 단어별로 검토하고 필요하면 변경합니다.
5. **검토 완료 · 시련 배포**를 누릅니다.

시련 유형은 뜻 고르기, 영어 고르기, 철자 입력, 철자 배열입니다. 객관식 힌트는 오답 2개를 지우고 입력형 힌트는 첫 글자와 영문 글자 수를 알려줍니다. 학생은 전체 문제를 최대 3회 도전하며 모든 문제를 맞히면 극복합니다. 문제당 완료 보상은 5 길드 코인입니다.

## 9. 학생에게 안내할 핵심

- 퀴즈 정답은 게임 성장과 길드 활동에 반영됩니다.
- 틀린 단어는 학습 기록에 남아 다시 출제되고 길드 시련에 활용될 수 있습니다.
- 한글이나 숫자를 잘못 입력한 경우 오답으로 처리하지 않고 안내 후 계속 수정할 수 있습니다.
- 길드 탈퇴나 내보내기 후에도 학생 개인의 학습·게임 기록은 유지됩니다.
- 월드보스는 전 학년이 공유 체력을 함께 줄이는 협동 콘텐츠입니다.

## 10. 스킬 획득·성장·합성·분해

### 캡슐과 연구 대상

- 퀴즈 보상으로 얻은 **FP**를 사용해 스킬 캡슐을 엽니다. 1회 50 FP, 10회 450 FP, 100회 4,500 FP입니다.
- 후보가 모두 있을 때 기본 결과 비중은 신규 스킬 40% · 보유 스킬 성장 50% · 각성 정수 10%(25개)입니다. 신규 또는 성장 후보가 없으면 가능한 결과로 비중을 다시 나눕니다.
- 정수 결과를 제외한 카드의 기본 등급 확률은 행운 보정과 10회 보장 적용 전 기준으로 일반 75% · 희귀 18% · 영웅 5% · 전설 1.95% · 신화 0.05%입니다.
- 카드 티어는 등급과 별도로 T3 70% · T2 25% · T1 5%입니다.
- 10회 단위 결과에는 가능할 때 신규 스킬 1장 이상, 성장 3회 이상이 보장됩니다. 카드 결과가 모두 일반이면 카드 1장이 희귀로 보정됩니다.
- 전투에는 스킬을 최대 4장 장착합니다. 원하는 글자의 스킬을 연구 대상으로 최대 4장 지정할 수 있고, 연구 대상 신규·성장 후보는 5배, 장착 스킬의 성장 후보는 2배 가중됩니다. 집중 성장 결과가 7회 연속 빗나가면 다음 성장 결과는 연구 대상이 됩니다.

### 성장과 진화

- 더 높은 등급 카드가 나오면 성급과 현재 성장 바의 **진행 비율**을 보존해 새 등급의 성장 바에 환산합니다. 함께 나온 티어가 현재보다 좋으면 그 티어도 즉시 적용됩니다.
- 같은 등급 또는 더 낮은 등급 결과는 현재 카드의 성장 칸을 1칸 올립니다. 이때 더 좋은 티어가 함께 나오면 먼저 적용합니다.
- 별 6개를 채운 뒤 다음 성장으로 T3→T2→T1 진화하며, T1 별 6개가 최대입니다.
- 각성 정수 100개로 원하는 보유 스킬의 성장 칸 1칸을 올릴 수 있습니다. 최대 성장 스킬에 들어온 초과 성장은 성장 칸당 각성 정수 100개로 전환됩니다.

### 카드 3장 합성

- 합성은 정확히 3장을 사용합니다. 신화 카드와 장착·연구·잠금 카드는 재료에서 제외됩니다.
- **같은 등급 3장**의 승급 확률은 `20% + 합산 누적 별 × 10%p + 세 카드의 현재 성장 바 진행률 합 × 5%p + 해당 등급 연속 실패 × 15%p`이며 최대 95%입니다. 성장 바 보너스는 카드당 최대 5%p, 합계 최대 15%p이고 연속 실패는 최대 5회까지 기록합니다. 성공하면 한 등급 상승하고 실패하면 같은 등급을 유지합니다.
- **서로 다른 등급 3장**은 카드마다 `등급 가중치 × 티어 계수 × 누적 별 계수 × 성장 바 계수`를 계산합니다. 등급 가중치는 일반/희귀/영웅/전설 = 1/3/9/27, 티어 계수는 T3/T2/T1 = 1/1.1/1.2, 누적 별 계수는 `1 + 누적 별 × 0.15`, 성장 바 계수는 `1 + 현재 성장 바 진행률 × 0.15`입니다. 세 가중치의 평균을 인접 등급 구간에서 확률로 환산하며 결과 등급은 재료 중 최고 등급을 넘지 않습니다.
- 결과 단어는 같은 가중치로 세 카드 중 하나를 선택하고 그 카드의 티어를 이어받습니다. 합성 결과의 성급과 현재 성장 바는 0에서 시작합니다.

### 분해와 각성 정수

- 신화 카드도 분해할 수 있습니다. 장착·연구·잠금 카드는 분해 대상에서 제외되고, 전설·신화 카드는 이중 확인 후 분해합니다.
- 반환 정수는 `등급 기본값 + 누적 별 × 50 + floor(현재 성장 바 진행률 × 50) + 티어 보너스`입니다. 등급 기본값은 일반/희귀/영웅/전설/신화 = 1/3/9/27/81, 티어 보너스는 T3/T2/T1 = 0/50/100입니다.

### 스킬 지수와 실제 피해

- 카드에 표시되는 스킬 지수는 `round(등급 기본 지수 × 티어 계수 × (1 + 누적 별 × 0.15))`입니다. 등급 기본 지수는 일반/희귀/영웅/전설/신화 = 5/10/20/40/70이고 티어 계수는 T3/T2/T1 = 1/1.1/1.2라서 전체 범위는 5~311입니다.
- 이 값은 표시용 **스킬 지수**이며 최종 피해를 그대로 뜻하지 않습니다. 스킬 피해 계수는 `1 + (목걸이 레벨 × 1.5 + 잠재력 스킬 피해 + 주문서 유물 스킬 피해) / 100`입니다.
- 일반 전투의 능력치 피해는 `floor(((클릭 공격력 × 지수 × 3) + (DPS × 2)) × 스킬 피해 계수)`입니다. 퀴즈 기본 피해에 `0.6 + min(1.9, (지수 - 5) / 60)`을 곱한 보정 하한과 능력치 피해 중 큰 값을 사용하고, 보스전 단일 스킬 피해는 보스 최대 체력의 10%를 넘지 않습니다.
- 월드보스는 `floor(전투력 × 2 × 지수 × 스킬 피해 계수 × 보스 상태 계수)`와 `floor(전투력 × 지수 / 2 × 보스 상태 계수)` 중 큰 값을 사용합니다. 보스 상태 계수는 보통 1, 골렘 일반 상태 0.4, 약점 파괴 상태 2.5(골렘 3.0)입니다. 따라서 같은 카드라도 공격력, DPS, 목걸이·잠재력·유물, 보스 상태에 따라 실제 피해가 달라집니다.

## 11. 개인정보와 권한

### 학생

- 필수 처리: 인증 UID, 닉네임, 학습 단어 학년, 게임 진행·학습 기록과 설정
- 수집하지 않음: 새 계정의 실명, 학교명, 반·번호, 주소, 전화번호
- 교사에게 보임: 길드원의 닉네임과 학습·게임 성취 데이터

### 교사

- Google 로그인 후 교사 이름, 학교명, 재직증명서로 재직 여부를 확인합니다.
- 공동 관리자는 같은 학교의 인증된 교사만 참여할 수 있습니다.
- 길드 폐쇄 시 길드 연결과 길드 데이터가 삭제되지만 학생 개인 기록은 유지됩니다.

## 12. 자주 묻는 문제

### 학생 설정이 바로 보이지 않아요

학생 화면을 새로고침하거나 앱을 완전히 종료 후 다시 실행합니다. 계속 기본값으로 보이면 교사 화면에서 해당 학생이 선택됐는지, 저장 완료 안내가 표시됐는지 확인합니다.

### 초대 코드가 동작하지 않아요

영문·숫자 6자리를 확인하고 만료 또는 교체된 코드가 아닌지 확인합니다. QR이나 참여 링크를 다시 생성해 전달할 수도 있습니다.

### 시련을 만들 수 없어요

뜻이 등록된 길드 누적 오답 단어가 최소 5개 필요합니다. 학생들이 먼저 일반 퀴즈를 진행하도록 안내합니다.

### 데이터가 늦게 보여요

새로고침을 한 번 누릅니다. 네트워크가 느린 경우 기존 캐시가 먼저 보일 수 있으며 새 데이터가 도착하면 갱신됩니다.

### 모바일 화면이 작아요

교사 관리 화면은 넓은 웹 화면을 축소해 전체 구조를 유지합니다. 가로 모드에서 필요한 영역을 확대해 확인하거나 PC·태블릿 사용을 권장합니다.

## 13. 첫 수업 권장 운영안

1. 수업 전: 교사 등록, 길드 생성, 기본 단어팩 설정
2. 수업 시작 5분: 학생 계정 생성과 길드 가입
3. 활동 10~20분: 퀴즈 전투 및 성장 기능 탐색
4. 수업 후: 참여·정답률·지원 필요 학생 확인
5. 다음 차시: 누적 오답 5문제 시련 배포

처음에는 게임의 모든 기능을 설명하기보다 **퀴즈 전투 → 보상 → 성장 → 길드 확인** 흐름만 안내하는 것이 좋습니다.
