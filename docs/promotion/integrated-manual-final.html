학생 계정

  • 실명 대신 한글·숫자 2~12자 별명

  • 전체 랭킹 공개는 선택

교사 계정

  • Google 교사 로그인
  • 학교 검색·교사 이름·재직증명서 확인
  • 같은 학교 길드 관리에만 사용

학생 계정에 저장하지 않는 정보서비스 운영에 사용하는 정보

기존 기록 가져오기: 업데이트 이전 기록이 있는 경우 가입 화면의 기능을 사용합니다. 이전 정보와 기존 기록이 한 번 일치할 때만 연결하며 해당 정보는 새 계정에 저장하지 않습니다.

3교사: 가입·길드·초대

교사 로그인Google 인증
재직 확인학교·이름·증명서
길드 생성기본 단어 수준
학생 초대코드·QR·링크

가입

  1. 첫 화면에서 교사 로그인을 선택합니다.
  2. Google 계정으로 인증합니다.
  3. 학교 검색 결과를 고르고 교사 이름을 입력합니다.
  4. 최근 1개월 이내 재직증명서를 제출합니다.
  5. 검토 완료 뒤 교사 길드 본부를 이용합니다.

길드와 권한

  • 처음 만든 교사는 길드 마스터입니다.
  • 같은 학교 인증 교사는 공동 관리자로 참여할 수 있습니다.
  • 학생용·공동 관리자용 초대 코드는 별도입니다.
  • 코드는 영문 대문자와 숫자가 섞인 6자리입니다.
재직증명서는 주민등록번호·주소·전화번호 등 불필요한 내용을 가린 뒤 제출합니다.

5교사: 맞춤 배정과 데이터 분석

길드 목록 → 길드 카드 → 길드원 관리

적용 대상

  • 개별 학생 직접 선택
  • 지원 필요·성장 중·안정 그룹
  • 전체 길드원
  • 전체 및 향후 가입자 기본값

학습 내용

  • 누적 단어팩 하나 선택
  • 초3~고3 하·중·상 누적 단계
  • 2022 개정 영어과 기본 어휘 3,000개 기반·표제어 3,001개 보존
  • 6개 문제 유형 복수 선택
적응형 경로: 문항 보충 모드는 선택팩 누적 풀이가 8회 이상이면서 정답률 75% 미만이거나, 미해결이 3개 이상이거나, 미해결 누적 오답 합계가 4회 이상이면 켜집니다. 후보가 모두 있을 때 미해결/직전/현재 단계의 기본 목표는 보충 55/30/15%, 평소 20/20/60%이며, 선택 그룹에 직전 문항과 다른 후보가 없으면 가능한 다음 그룹으로 재배분합니다. 이전 학년은 교사가 직접 지정합니다. 학생 리포트에서 실제 배정팩·출처, 기본 목표 비중과 진입 근거를 확인하며, PC에서는 상단을 접어 리포트 공간을 넓힐 수 있습니다.

7학생: 영단어 학습과 채점

9학생: 성장·수집·협동

장비·잠재력

퀴즈 보상으로 강화하고 전투력을 높입니다.

펫·유물

수집 효과와 전투·학습 보너스를 누적합니다.

스킬

퀴즈 FP 캡슐로 얻고 성장시켜 최대 4장을 전투에 장착합니다.

차원 영웅

50종×5등급 외형, 장착 효과와 도감을 수집합니다.

길드 성장

길드 코인 상점과 포인트 공용 효과를 이용합니다.

월드보스

퀴즈·스킬·보스 패턴을 결합한 전 학년 협동 레이드입니다.

스킬 핵심: 퀴즈 FP로 캡슐을 열며 1/10/100회는 50/450/4,500 FP, 장착은 최대 4장입니다. 후보가 있을 때 신규/성장/정수 기본 비중은 40/50/10%이고, 카드 기본 등급은 일반/희귀/영웅/전설/신화 75/18/5/1.95/0.05%, 티어는 T3/T2/T1 70/25/5%입니다. 상위 등급은 성급과 현재 성장 바 비율을 보존하고 좋은 티어를 즉시 적용하며, 같은·하위 등급은 성장 1칸입니다. 6성 뒤 T3→T2→T1, T1 6성이 MAX입니다.
합성·분해·피해: 합성은 정확히 3장입니다. 동일 등급 승급률은 20% + 합산 누적 별×10%p + 성장 바 진행률 합×5%p(최대 15%p) + 연속 실패×15%p, 전체 최대 95%입니다. 혼합은 등급 1/3/9/27 × 티어 1/1.1/1.2 × (1+누적 별×0.15) × (1+성장 바 비율×0.15)의 평균이며 최고 재료 등급을 넘지 않고 결과 별·성장 바는 0입니다. 신화는 합성 불가지만 분해할 수 있습니다. 표시 지수는 등급 5/10/20/40/70 × 티어 × 별 계수를 반올림한 5~311이며 실제 피해는 공격력·DPS·보너스·퀴즈 피해 하한·보스 보정으로 계산되고 일반 보스 단일 스킬은 최대 체력 10%가 상한입니다.
월드보스: 같은 날 중도 이탈 기록은 이어서 플레이하며, 날짜가 바뀌면 누적 피해가 최종 정산됩니다. 리치의 저주 해제 미니퀴즈 동안에는 레이드 타이머가 멈춥니다.
